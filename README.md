# Ishan Jain — Portfolio

Premium personal portfolio for Ishan Jain, Associate Software Engineer.

## Stack

- React + TypeScript (Vite)
- Tailwind CSS v4
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit content in `src/data/content.ts` — experience, projects, skills, and profile links.
